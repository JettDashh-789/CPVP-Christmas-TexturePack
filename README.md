# 🎄 CPVP Pack by JettDashh

A custom Minecraft resource pack designed for Crystal PvP.

## ✨ Features

- Custom End Crystals
- Custom Totems
- Custom Swords
- Custom Golden Apples
- Custom Ender Pearls
- Custom Obsidian
- Custom Inventory and Chest GUI
- Custom HUD and Hearts
- Christmas-themed Netherite and Diamond Armor
- Low Fire
- Reduced explosion particles
- Static Water and Lava

## 🎮 Compatibility

Minecraft Java Edition 1.21 – 26.1.2
